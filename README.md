# Python Calculator

My first project in my Python learning journey, and I'm very proud of this beginning.

## Features
- Basic arithmetic operations (+, -, *, /).
- Continuous calculation using a `while` loop.
- Input validation: handles invalid numbers and invalid operations.
- Division by zero protection.

## How to run
1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python calculator.py
```
